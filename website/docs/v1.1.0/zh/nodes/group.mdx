# 分组 `group`

分组容器把一组节点收进一个子画布，外层画布只看到一个步骤：从 `in` 进入，子画布执行一次，完成后从 `done` 继续。它适合把一段相对独立的工作（例如一份子计划、一个地区的评估）放在一起展示和审阅，而不必拆成一个有独立历史的子工作流。

## 结构

`start_node_id` 必须指向容器内唯一的 `group-start`。所有子节点使用容器 ID 作为 parentId，内部入口的 `next` 连接第一项工作。边不能跨出容器；外层节点读取的是容器本身的结果。分组里可以再放遍历集合或条件循环。

## 和子工作流的区别

分组只描述图结构，不生成运行命令，宿主决定如何把子画布编译成步骤。需要自己的历史、状态和取消策略时，使用[子工作流](./child-workflow)。需要对一组输入重复执行时，使用[遍历集合](./iteration)。
